# 🚀 StartupScout AI

### Validate Startup Ideas Before You Waste Months Building Them

StartupScout AI is an AI-powered startup validation platform that helps founders evaluate business ideas through automated market research, competitive analysis, risk assessment, and strategic recommendations.

Built for entrepreneurs who want data-driven insights before investing time and resources into a new venture.

---

## 🌐 Live Application

**Try it here:** https://startupscout-ai.vercel.app

---

## ✨ Features

### 🔍 AI Startup Validation

Analyze startup concepts using advanced AI-powered research workflows.

### 📊 Market Opportunity Analysis

Evaluate market size, demand, trends, and growth potential.

### 🏆 Competitor Intelligence

Identify existing competitors and uncover market gaps.

### ⚠️ Risk Assessment

Highlight operational, financial, and execution risks before launch.

### 🎯 Strategic Recommendations

Receive actionable insights and next-step guidance.

### 👤 Founder Dashboard

Manage startup analyses and track validation history.

### 🔐 Secure Authentication

User registration, login, and session management powered by Supabase.

### ☁️ Cloud Persistence

All projects and user data are securely stored in PostgreSQL via Supabase.

### 📈 Portfolio Tracking

Maintain a centralized repository of startup validation reports.

## 🚀 Local Development

Clone the repository:

```bash
git clone https://github.com/ByteBlaze1706/startupscout-ai.git
cd startupscout-ai
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file:

```env
GEMINI_API_KEY=your_gemini_api_key

SUPABASE_URL=your_supabase_url

SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
```

Run the development server:

```bash
npm run dev
```
